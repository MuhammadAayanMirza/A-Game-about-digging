# The Last Dig

![](https://cdn.hackclub.com/01a0bd60-7493-7882-8ac5-cf5f0bf29397/Screenshot%202026-09-20%20at%2010.52.26.png)
 
 A Digging Game where your goal is to reach the bottom
 of the world by upgrading your tools using minerals that you'll find on the way.

 Play it here: 

 ### Controls:

  - **W/A/S/D** or **Arrow Keys** for movement.
  - **Left Click** a Grass/Dirt Tile to Dig it.
  - To Use Jetpack Press **Spacebar**.
</br>

## Upgrades Menu
There are currently 4 Unique Upgrades: </br>

![](https://cdn.hackclub.com/01a0bd6c-6987-74bd-807f-940fb0b7035e/Screenshot%202026-09-20%20at%2011.06.15.png)

>### Shovel Upgrade

 This increases how many tiles you can dig.

>### Inventory Upgrade

This increases your inventory space.
</br>
(Starting inventory space is 3 items)

>### Battery Upgrade

This increases the jetpack's battery capacity.

>### Jetpack Upgrade

This increase the jetpack's speed.

## Other Features

- Battery drains so don't forget to refill.
- Coal tile = 10M
- Iron tile = 15M
